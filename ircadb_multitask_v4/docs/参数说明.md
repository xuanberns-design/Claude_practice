# 配置参数完整说明

所有配置优先从所选 YAML 读取；没有写在 YAML 的字段才使用 `src/config.py` 中 `Config` 默认值。下表值是 **configs/default.yaml 的兼容配置值**；质量增强方案见 configs/enhanced_native512.yaml。路径相对运行命令的当前目录，建议使用正斜杠和带引号的绝对路径。

参数值是合理起点，尚未通过用户完整数据证实最优。改变数据、投影、分辨率或签名字段必须新建缓存；改变训练策略必须新建run。CV初始化后不编辑fold配置，改参须建立新协议。

## 文件开头的展示参数

`src/visualize.py` 顶部集中设置 `FIGURE_SIZE、FIGURE_DPI、LIVER_COLOR、TUMOR_COLOR、LIVER_ALPHA、TUMOR_ALPHA、TITLE_SIZE`。它们只改变图片外观，不能修改实际分割指标。

`src/crossval.py` 顶部 `K_FOLDS=5` 固定本次五折协议；本版本的协议验证与测试围绕5折设计，不建议只改该数字。`src/cache_quality.py` 顶部 `QUANTILES` 指定HU分布审计的分位点。网络拓扑和损失公式位于对应模块，属于实现而非普通运行参数。

## 增强方案与显存选择

`configs/enhanced_native512.yaml` 在上表兼容配置上把 image_size/patch_size 改为 512/256，base_channels/batch_size 改为 24/1，CUDA AMP 开启，32/64/128 视角抽样权重改为 0.6/0.2/0.2。开启 RCAB + PixelShuffle、tumor_boundary_sample_probability=0.5、patch_center_jitter_fraction=0.125、liver_hard_negative_weight=0.2、seg_boundary_weight=0.2、laplacian_weight=0.05。这些是**待真实数据验证的预设实验值**，不应根据测试患者逐项调参。`configs/enhanced_256_low_memory.yaml` 保持同一增强机制，但使用 image_size=256、patch_size=null、base_channels=16、batch_size=1；细节上限仍受256缩小影响。

如果显存不足，先在新实验 YAML 将 base_channels 降至16，或使用低显存方案；模型结构变化时旧 checkpoint 不能续训。标签定义改动使两个方案均须新缓存、新 audit、新权重。每个新配置在五折开始前冻结；不同配置比较时固定患者划分、模拟投影协议和指标口径。
